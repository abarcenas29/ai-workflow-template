## Decision / Recommendation

### Change Plan

The goal is: rename `opencode.mcp.example.json` → `opencode.mcp` AND delete `opencode.mcp.json` from the repo. The new canonical name is `opencode.mcp` (no `.example`, no `.json` extension).

| # | File | Action |
|---|------|--------|
| 1 | `opencode.mcp.example.json` | **RENAME** → `opencode.mcp` |
| 2 | `opencode.mcp.json` | **DELETE** (untracked, gitignored file) |

| 6 | `scripts/sync.js` line 374 | Update manifest tracking key to `'__root__/opencode.mcp'` |
| 7 | `package.json` line 52 | Change `"opencode.mcp.example.json"` → `"opencode.mcp"` |

#### On the auto-copy block (lines 370-381 of sync.js):

**RECOMMENDATION: Remove the auto-copy block entirely.** Since `opencode.mcp` will now be a tracked file in the template repo AND synced as a root file to consumers, the consumer gets `opencode.mcp` directly. There's no separate "example" → "live" distinction anymore — one file serves both purposes.

If the intent is to keep the auto-copy (e.g., some consumers might have their own custom `opencode.mcp`), the block should be changed to copy `opencode.mcp` → `opencode.mcp` (self-copy, essentially a no-op). But this is semantically meaningless — better to remove it.
